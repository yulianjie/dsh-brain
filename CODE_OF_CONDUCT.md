# Code of Conduct / 社区行为准则

We welcome contributors of all backgrounds and experience levels. Use respectful
language, critique ideas and code rather than people, and help others participate.
中文和英文交流均受欢迎，请尊重不同经验与背景的参与者。

Harassment, threats, discriminatory or sexualized abuse, deliberate disruption,
and disclosure of another person's private information are unacceptable. Do not
post private conversations, credentials or memory exports without consent.

This policy applies to repository Issues, pull requests, reviews and other
project-managed community spaces. Maintainers may edit or remove abusive content,
warn participants, or restrict participation according to the severity and pattern
of behavior. Decisions should be explained respectfully without exposing private
details.

Report a conduct concern privately through the contact methods, if available, on
the [maintainer's GitHub profile](https://github.com/yulianjie). If no private
contact method is available, request one without publishing incident details.
Use GitHub's Report abuse feature for platform abuse. Security vulnerabilities
have a separate reporting channel in [SECURITY.md](SECURITY.md).
