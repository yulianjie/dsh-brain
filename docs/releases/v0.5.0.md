# DSH Brain v0.5.0

本版本解决两个写入端缺陷：近似重复记忆长期并存（同一路径的 key 命名风格不同或措辞转述时，旧的精确匹配无法合并），以及瞬时任务状态（CI 状态、测试结果、分支名、状态汇报）被自动提取存为长期记忆。方案为写入时的三层防线，全部保持 `schemaVersion=1`、零新增持久字段与零新增依赖。从 0.4.1 升级无需迁移，已有记忆原样保留。

## 主要变化

### 层 1：写时确定性去重合并

- `Brain._remember` 对同 scope、同 workspace 的既有记录按五级判据首中即止：精确 key、归一化文本精确、canonical key（小写字母数字形式，两侧 ≥8 码位，kebab-case 与 snake_case 的同一语义 key 可合并；两文本还需至少共享一个词项，零重叠的不同事实不因 key 碰撞合并）、归一化文本包含关系（较短侧 ≥6 码位）、term-Jaccard 相似度 ≥0.75（复用 `lib/text.js` 分词）。
- 命中即合并而非新建：保留既有 id 与 createdAt、刷新 updatedAt、confidence 取两侧最大、key 取既有 key（无则取新 key）、`personalityTraits` 取并集；文本按「保留信息量最大」裁决——新文本短于既有文本的 60% 时保留既有富文本，否则新文本胜出（纠正语义保留），kind/source 跟随胜出文本。
- 相似度门槛取 0.75，高于 dream 的 0.6 人工复核门槛：写时自动合并没有复核环节，0.6–0.75 区间的转述交由模型层 updateOf 或 dream 复核处理。
- `similarity()` 从 `lib/dream.js` 移到 `lib/text.js` 导出，dream 改为导入，行为不变。
- 例外：显式点名改写（`automatic=false` 且带 `id`，即模型工具传 `id`、CLI `update` 命令）保持纯替换语义，不受 60% 规则约束。
- `brain_remember` 工具返回增加 `merged` 布尔字段（本次写入命中既有记录时为 true，返回的 id 即目标记录），工具描述同步说明「同 scope 相似记忆会合并而非新建重复」；`/brain remember` 与 `remember()` API 仍返回完整记录。

### 层 2：记忆价值门槛

- `validateExtraction` 的 memories 分支新增临时性守门（feedback 不受影响）：纯 URL、git ref 形状、`文件:行号`、`结果/状态/进度/输出/日志:` 引导、状态 emoji 引导、状态收尾谓词（有问题/报错/失败了/没通过了/修好了等，含完成态「了」后缀）、测试与构建结果快照（verify/ci/build + pass/passes/passing/fail/fails/failing 等词形）一律 `rejected` 丢弃，即使模型置信度很高。
- 豁免优先：包含句以「请记住/记住/remember」开头，或含 durable cue（以后/今后/往后/一直/每次/总是/always/from now on，与风格学习共用同一词表）时不过滤——显式意图压倒启发式。
- 离线 fallback 的产物（请记住句、风格句）不受影响。

### 层 3：模型路径 updateOf

- 后台提取注入 top-10 同 scope 相似既有记忆为 `EXISTING` 上下文（id + key + 文本截 200 码位，只读检索；读取失败降级为空列表，提取不依赖存储可读性）。
- 提取提示词加入价值门槛（「未来的 assistant 会因为这条内容而合理地表现更好吗」）、时效措辞与 updateOf 协议说明；`lib/extraction.js` 的独立 `extractionPrompt()` 同步措辞。
- 模型对重述或更新既有记忆的候选可返回 `updateOf`（非空字符串 ≤100 字符，校验时透传），`learn()` 在同一事务内解析目标（同 scope，workspace 时同路径）：命中则按 informative 策略更新该条；未命中（已删除或跨 scope）降级为普通新增，不抛错。

## 兼容性与升级

- 包名仍为 `@yulianjie/dsh-brain`，`id: brain`、默认存储路径和 schemaVersion=1 不变；升级保留已有记忆、风格、历史和配置，无需迁移。
- 零新增持久字段，`validateState()` 白名单不变，无新增依赖；命令、六个模型工具与 23 项原生设置不变（`brain_remember` 返回体增加 `merged` 字段）。
- 行为变化：写入相似记忆不再新建重复记录；瞬时任务状态不再入库；已被删除的记忆被 `updateOf` 指向时降级为普通新增。
- Desktop 集成目标仍为 **Windows bundled runtime 0.2.1-rc.3**；Node 核心和 CLI 要求 Node 22+。

## 安装

```powershell
$dshCli = Join-Path $env:LOCALAPPDATA 'Programs\DeepSeek Harness\resources\runtime\cli\bin\dsh.cmd'
& $dshCli plugin --profile desktop add '@yulianjie/dsh-brain@0.5.0'
```

或下载附件 `yulianjie-dsh-brain-0.5.0.tgz` 与 `SHA256SUMS.txt`，核对校验值后执行：

```powershell
$expected = ((Get-Content .\SHA256SUMS.txt -Raw).Trim() -split '\s+')[0]
if ((Get-FileHash .\yulianjie-dsh-brain-0.5.0.tgz -Algorithm SHA256).Hash -ne $expected) { throw 'SHA256 mismatch' }
& $dshCli plugin --profile desktop add (Resolve-Path .\yulianjie-dsh-brain-0.5.0.tgz).Path
```

正常退出并重新启动 Desktop，在插件页面确认组件运行，再执行 `/brain status`。
