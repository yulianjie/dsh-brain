# DSH Brain v0.4.0

本版本把注入给模型的交流风格从数值改为固定的中文行为说明，新增只读的记忆合并规划，并修复风格学习读反、误学和进程崩溃后写锁无法恢复等问题。

## 主要变化

### 风格以文字说明注入

- 模型看到的不再是 `{"mode":…,"traits":…}` 这样的数值，而是按五个维度分档生成的固定中文句子，例如「回答偏简短：先给结论，最多补一两句理由。」；五个维度都处于中间档时注入一句中性说明。档内的小幅变化不会改变注入文字。
- 预算不足时优先保留长期记忆，放不下的风格说明会被省略。

### 只读的记忆合并规划

- 新增 `/brain dream [--json]` 与 `brain.dreamPlan()`：在同一作用域和工作区内找出重复或相近的记忆，列出合并候选组。只读取存储，不写入，也不迁移数据。
- 候选组和生成的模型输入都有数量与长度上限；结构不合法的计划会被拒绝，合并后的索引行不允许出现原文没有的词。

### 风格学习更可靠

- 本地规则能正确识别否定、弱化和抱怨的说法：「请少开玩笑」「别那么正式」「回答太长了」「Please don't be so formal」不再被读成相反方向；本地规则与模型方向冲突时，这一维度当轮不学习。
- 只有在谈论回答方式时才学习风格。「以后有问题直接找我」「两个问题都详细回答一下」「Could you give me a detailed explanation of closures?」这类普通请求不再改变风格。
- 提取模型正常返回时，风格只按模型给出的、带用户原文证据的反馈学习；本地规则只在模型不可用（超时、出错、输出无法解析）时兜底。
- 「在所有项目里……」判为全局偏好；指名具体项目的句子仍只作用于该项目。
- 学习步长的死区两端对称：连续同向反馈分别收敛到 0.15 和 0.85。

### 写锁自动恢复

- 同一台机器上崩溃进程留下的 `.brain.lock`，在确认原进程已退出后会自动接管。其他主机留下的锁、旧格式的锁以及仍在运行的写入者，仍按原来的方式等待超时并提示手动处理；删除锁失败时也会按超时报错，不会反复重试。

## 兼容性与升级

- 包名仍为 `@yulianjie/dsh-brain`，`id: brain`、默认存储路径和 schemaVersion=1 不变。升级保留已有记忆、风格、历史和配置。
- 模型可见的 Brain 参考文本中，风格部分由 JSON 改为中文句子。如果有脚本解析这段文本，需要相应调整。
- 模型正常工作时，模型漏掉的明确风格说法不再由本地规则补学；需要立刻固定风格时，可使用手动模式、`/brain personality` 或冻结。
- 新写入的锁信息多了 `host` 字段；0.4.0 之前留下的锁不会被自动接管。
- 新增 `/brain dream`，其他命令、六个模型工具和 23 项原生设置不变。
- Desktop 集成目标仍为 **Windows bundled runtime 0.2.1-rc.3**；Node 核心和 CLI 要求 Node 22+。

## 安装

```powershell
$dshCli = Join-Path $env:LOCALAPPDATA 'Programs\DeepSeek Harness\resources\runtime\cli\bin\dsh.cmd'
& $dshCli plugin --profile desktop add '@yulianjie/dsh-brain@0.4.0'
```

或下载附件 `yulianjie-dsh-brain-0.4.0.tgz` 与 `SHA256SUMS.txt`，核对校验值后执行：

```powershell
$expected = ((Get-Content .\SHA256SUMS.txt -Raw).Trim() -split '\s+')[0]
if ((Get-FileHash .\yulianjie-dsh-brain-0.4.0.tgz -Algorithm SHA256).Hash -ne $expected) { throw 'SHA256 mismatch' }
& $dshCli plugin --profile desktop add (Resolve-Path .\yulianjie-dsh-brain-0.4.0.tgz).Path
```

正常退出并重新启动 Desktop，在插件页面确认组件运行，再执行 `/brain status`。

## 验证

- 179 项测试，覆盖风格说明渲染、dream 规划与校验、20 句否定和弱化说法的方向、模型可用与不可用两条学习路径、残留锁接管与删除失败超时等；从干净检出运行 `npm run verify`（语法、文档链接、包元数据、测试与 tarball 干净安装）通过。
- Desktop bundled runtime 0.2.1-rc.3 冒烟测试（合成模型，不读取用户 profile、不调用网络模型）：30 轮长会话中每轮最多一个当前 Brain 参考，严格磁盘恢复、压缩后恢复、旧快照迁移、宿主 token 统计、23 项设置保存与重启均通过。
- 在独立的 `DSH_HOME` 和 profile 中用 Desktop 自带 CLI 安装发布包，对已安装的包重跑上述冒烟测试，然后卸载。
- 本地风格规则另用 174 句中英文说法核对：读反 0 句；误学 1 句，是同一轮里先要求简短、又要求复杂问题详细回答的混合句。
- 验证边界：本版本没有做真实网络模型验收；原生设置界面没有改动，未重新做界面验收；没有在其他宿主版本上验证。
