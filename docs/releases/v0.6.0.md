# DSH Brain 0.6.0 verification record

Local source, package, Desktop runtime and remote release checks passed.
GitHub Release and npm version 0.6.0 are public and contain the same tarball.

## Local package checks

- `npm run verify` passed on Node.js 24.14.1, including all 289 tests, syntax,
  package metadata, local documentation links and clean tarball installation.
- `node --test test/package.test.mjs` passed.
- `npm run pack:check` passed with a clean temporary install. It verified the
  43-file tarball, package import, SQLite CLI persistence and JSON export with
  `schemaVersion: 1`.
- The package check used synthetic data. Node.js 24.14.1 emitted the built-in
  `node:sqlite` ExperimentalWarning.

## Desktop runtime checks

- Host: Desktop bundled runtime 0.2.1-rc.5, Electron 44.7.0 and Node.js 24.21.0;
  app.asar supplied Cordis 4.0.5 and agentLoop 0.2.1-rc.5.
- Runtime smoke exercised 82 model requests and 40 extraction calls through a
  synthetic provider adapter across 30 long-conversation turns. The observed
  single Brain snapshot was at most 752 characters.
- Coverage included six native model tools, 23 settings, strict persisted-log
  recovery, compaction, conversation/workspace isolation, SQLite persistence,
  configuration retention and system trust-policy registration.
- The provider was synthetic. This was not an online LLM quality evaluation.

## Storage and permission checks

- The final full suite passed 289/289 on both Node.js 24.14.1 and the exact
  minimum Node.js 22.13.0; actual-host runtime smoke also passed.
- Automated tests cover SQLite migration, transactional rollback, concurrent
  writers, byte-for-byte preservation of the legacy JSON input, summaries with
  separate evidence, bounded replay retention and import after deletion.
- Deletion markers distinguish records even when separate claims share the same
  evidence. Evidence replay protection uses a stable property key when available;
  without one, arbitrary paraphrased replays are not guaranteed to match.
- Root agents may mutate memories. Child agents retain read-only memory tools but
  receive no injected Brain reference; write and forget tools and `/brain`
  mutation commands require a confirmed root agent.
- Node.js 22.13 is the declared minimum because it provides `node:sqlite` without
  a startup flag. The exact Node.js 22.13.0 Windows binary passed the full test
  suite; local runtime checks also used Node.js 24.14.1 and 24.21.0. CI targets
  the Node 22 and 24 release lines.

## Local installation

A locally built 0.6.0 tarball was installed through Desktop's bundled CLI. Its
JavaScript files matched the verified workspace source. The installed package
passed the synthetic-provider runtime smoke. The installer did not read or modify
the live memory store; SQLite migration waits until the normal Desktop restart
loads the package.

The release workflow creates `SHA256SUMS.txt` for the tagged archive and compares
the GitHub Release and npm registry tarballs. A separately built local validation
tarball is not the release artifact or its authoritative checksum.
