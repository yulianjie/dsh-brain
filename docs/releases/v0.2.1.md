# DSH Brain v0.2.1

首次公开正式版本，使用 **Apache License 2.0**，npm 包名为
**`@yulianjie/dsh-brain`**。GitHub 仓库仍为 `yulianjie/dsh-brain`，管理 CLI
命令仍为 `dsh-brain`。npm 上不带 scope 的同名包属于其他项目，请勿混用。

## 功能

- 本地长期记忆：跨会话持久化、全局偏好与工作区事实隔离、中英文检索、纠正合并、
  删除标记、导入导出与原子写入保护。
- 自动学习：只从已完成根轮次的用户原文提取，要求逐字证据；有界队列、超时与
  本地明确偏好兜底，每轮最多一次模型调用，排除助手/工具/子 agent 内容。
- 交流风格：亲切度、详细程度、幽默、主动性、正式程度五个维度，至少三个独立
  反馈轮次后渐进调整；每轮变化最多 0.05，支持人工设置、冻结、重置、历史和回退。
- 原生配置：Desktop 内 20 项设置、六个分组、自动/手动/关闭模式、独立学习与注入
  开关、模型路由校验、配置保存与重启恢复；手动覆盖不改写已学习状态。
- 管理入口：`/brain` 命令、五个模型工具、返回 JSON 的独立管理 CLI。

## 相对本地 0.2.0 的变化

- 项目许可调整为 Apache-2.0，添加 NOTICE 与依赖许可清单。
- 正式包名改为 `@yulianjie/dsh-brain`，同步 Cordis bundle、浏览器模块 ID、原生
  配置插槽和卸载目标，避免发布或安装其他维护者的同名项目。
- 安装脚本发现旧本地 unscoped 依赖时明确停止，避免重复注册 `id: brain`。
- 补充中英文说明、贡献指南、安全政策、故障排查、发布检查、Issue/PR 模板。
- 添加 Node 22/24 × Windows/Linux/macOS CI、实际 tarball 安装检查和 scoped
  包名的真实宿主加载验证。运行时测试可通过 `DSH_BRAIN_PACKAGE_DIR` 检查下载后的安装包。

## 兼容性

- Desktop 集成目标：**Windows DeepSeek Harness bundled runtime 0.2.1-rc.3**。
- 核心与独立 CLI：Node.js **22 或以上**；CI 覆盖 Node 22 和 24，三个操作系统。
- 安装脚本：Windows PowerShell；原生设置与 CLI 帮助目前为中文。
- 不保证其他 Desktop 版本或 Linux/macOS 原生 Desktop 界面的兼容性。
- 存储 schemaVersion=1、默认数据目录与 `id: brain` 不变，没有数据迁移或重置。

## 下载与校验

附件：

| 文件 | 用途 |
| --- | --- |
| `yulianjie-dsh-brain-0.2.1.tgz` | 可安装的 npm 插件包，含源码、原生客户端、安装卸载脚本、文档与许可证 |
| `SHA256SUMS.txt` | 该 tarball 的 SHA256 校验值 |

GitHub 自动生成的 Source code 归档是源码快照，不是上述 npm 安装包。
将两个附件放在同一目录，PowerShell 校验：

```powershell
$expected = ((Get-Content .\SHA256SUMS.txt -Raw).Trim() -split '\s+')[0]
$actual = (Get-FileHash .\yulianjie-dsh-brain-0.2.1.tgz -Algorithm SHA256).Hash
if ($actual -ne $expected) { throw 'SHA256 mismatch' }
```

## 安装

从 GitHub 下载后：

```powershell
tar -xf .\yulianjie-dsh-brain-0.2.1.tgz
.\package\scripts\install.ps1 -PackagePath .\yulianjie-dsh-brain-0.2.1.tgz
```

从 npm 安装到 Desktop：

```powershell
$dshCli = Join-Path $env:LOCALAPPDATA 'Programs\DeepSeek Harness\resources\runtime\cli\bin\dsh.cmd'
& $dshCli plugin --profile desktop add '@yulianjie/dsh-brain@0.2.1'
```

正常重启 Desktop，在插件列表确认 `@yulianjie/dsh-brain`，执行 `/brain status`。
独立管理 CLI 则用 `npm.cmd install -g @yulianjie/dsh-brain@0.2.1`，然后
`dsh-brain --help`；全局安装不自动启用 Desktop 插件。安装过程需要访问 npm 依赖源。

## 从旧本地包升级

1. 导出私人记忆备份，并保留现有 profile 配置与自定义 `dataDir`。
2. 使用 Desktop bundled CLI 对原 profile 执行 `plugin --profile desktop remove dsh-brain`。
3. 安装本版本 scoped 包；不要从 npm 安装旧名称。
4. 保持相同 `DSH_HOME` / `dataDir` 与 `id: brain` 配置覆盖，正常重启 Desktop。

卸载旧包不会删除存储；原有记忆、学习风格、历史与冻结状态继续使用。不要同时启用
旧包和新包。安装脚本不自动结束 Desktop，不自动修改其他 profile 或删除数据。

卸载本版本：`& $dshCli plugin --profile desktop remove '@yulianjie/dsh-brain'`，或
运行 `.\package\scripts\uninstall.ps1`，然后正常重启。记忆文件仍然保留。

## 验证与限制

发布检查包括全部行为测试、三平台 CI、实际包安装，以及真实 bundled runtime 的
scoped loader、客户端 ID、设置持久化、跨会话召回、工作区隔离与风格保留。
发布后还需下载 GitHub 和 npm tarball，核对 SHA256 / npm integrity，并在隔离
`DSH_HOME` 中通过 bundled CLI 安装与卸载。实际完成结果在 Release 验证记录中补充。

本版本没有声称重做原生窗口验收或真实联网模型效果测试。运行时 smoke 使用合成
provider，不读取现有聊天或认证信息。CI 通过不等于每个平台的原生 Desktop 验收。

本地存储为明文 JSON；自动提取通过宿主模型处理本轮用户文本，召回记忆进入后续
模型上下文，可能产生费用。凭据过滤和检索是启发式，无法保证识别全部秘密或始终
准确召回。用户可查看、修改、遗忘、冻结及关闭学习；请勿公开记忆导出文件。

## English summary

First public release of **`@yulianjie/dsh-brain@0.2.1`**, licensed under Apache-2.0.
It provides local scoped memory, evidence-based background learning, gradual and
controllable communication style, native Desktop settings, commands/tools and a CLI.
The unscoped npm name belongs to another project. Remove the old local package
before installing this scoped release, keeping the same data directory and profile
overrides. Node.js 22+ is required for the CLI; native integration targets Windows
Desktop bundled runtime 0.2.1-rc.3. Verify the tarball against `SHA256SUMS.txt` before
installation. Local plaintext storage does not make model-assisted learning offline.
