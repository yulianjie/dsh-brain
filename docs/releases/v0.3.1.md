# DSH Brain v0.3.1

本版本修复长期聊天中 Brain 参考快照累积、记忆工具输出无总预算的问题，并改进全局偏好召回和渐进性格的稳定性。

## 修复 v0.3.0 的磁盘恢复问题

v0.3.0 已撤回：首次请求准备阶段过早追加 Brain 参考，导致它排在宿主首条系统消息之前；运行中可工作，但重启时严格日志解码器拒绝恢复。v0.3.1 将首条参考放入 pre-step 决策，由宿主在系统消息后提交；后续仍只替换 Brain 节点。

运行时验收现在逐轮通过真实持久化 codec 编码和严格恢复，并明确测试错误顺序必须被拒绝。升级不会自动改写已经受影响的旧会话日志；遇到该问题应保留原件并单独修复，长期记忆文件不受影响。

## 主要变化

- 模型输入保留一个当前 Brain 参考消息。内容变化时通过宿主单节点替换协议更新；原始会话事件保留，其他插件分节不受影响。
- `brain_list` / `brain_search` 改为分页预览，新增 `brain_read` 分段读取全文；游标绑定可见结果和范围，普通聊天计数不打断分页。
- 自动参考和记忆工具分别受字符及估算 Token 双预算约束。默认均为 6000 字符 / 2000 估算 tokens；原生设置由 20 项增至 23 项。
- 少量全局 preference/instruction 可在无关键词重合时召回；全局记忆在同一存储内跨会话、跨工作区共享，工作区记录继续隔离。
- 性格更新要求最近最多 5 次反馈中至少 3 次、至少 75% 同向支持且最新反馈同向；每次最多变化 0.05，使用中位数与死区抑制抖动。项目限定和临时反馈不训练全局性格。

## 兼容性与升级

- 包名仍为 `@yulianjie/dsh-brain`，`id: brain`、默认存储路径和 schemaVersion=1 不变。升级保留已有记忆与配置。
- 工具 API 变化：列表和搜索现在返回 `{records,total,nextCursor}`，不再返回裸数组；需要全文时调用 `brain_read({id,cursor?})`。本地 CLI 的 list/export 保持完整输出。
- Desktop 集成目标为 **Windows bundled runtime 0.2.1-rc.3**，需要宿主 session surface replacement 与 tokenMeter；Node 核心和 CLI 要求 Node 22+。
- 替换较早参考消息可能降低提示词前缀缓存命中率。局部预算不限制其他插件、全部聊天历史或累计工具输出；估算 token 不是精确计费或超窗保证。

## 安装

```powershell
$dshCli = Join-Path $env:LOCALAPPDATA 'Programs\DeepSeek Harness\resources\runtime\cli\bin\dsh.cmd'
& $dshCli plugin --profile desktop add '@yulianjie/dsh-brain@0.3.1'
```

或下载附件 `yulianjie-dsh-brain-0.3.1.tgz` 与 `SHA256SUMS.txt`，核对校验值后执行：

```powershell
$expected = ((Get-Content .\SHA256SUMS.txt -Raw).Trim() -split '\s+')[0]
if ((Get-FileHash .\yulianjie-dsh-brain-0.3.1.tgz -Algorithm SHA256).Hash -ne $expected) { throw 'SHA256 mismatch' }
& $dshCli plugin --profile desktop add (Resolve-Path .\yulianjie-dsh-brain-0.3.1.tgz).Path
```

正常退出并重新启动 Desktop，在插件页面确认组件运行，再执行 `/brain status`。

## 验证

- 69 项测试：500 条长记忆分页、Unicode 原文读回、预算、全局召回、范围隔离、性格矛盾反馈、冻结、重启等。
- 实际已安装包的 Desktop bundled runtime 验证：30 轮最多一个当前快照、压缩恢复、旧快照分节迁移及 token 统计一致。
- 原生设置页确认 23 项字段及组件运行；修正版新建真实会话完成工具调用后，完整退出并重启 Desktop，历史恢复正常。
- DeepSeek-V4.1-Flash 真实聊天完成全部六个工具的调用：列表、搜索、写入、全文读取、性格查询，以及已删除测试 ID 的幂等遗忘；第二个新会话成功召回合成全局记录。
- 验收后合成记录已清理；原有记忆、性格、风格历史和两份配置保持一致。仅增加正常轮次去重记录与合成记录的删除标记。
- 长期性格状态稳定性由确定性测试和合成运行时验证；真实模型验收验证调用、跨会话召回及临时要求不改变性格，不代表所有模型的长期风格表现保证。
